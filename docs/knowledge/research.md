# Research: what Scout finds and how to trust it
Last reviewed: 2026-11-11

For Scout, the Orchestrator and the critic. Scout works alone on a topic from Kyle and writes `research`
rows; nothing it does moves a task. Outside numbers go stale fast, so every one carries a date.

## Rules

- Research only: write to the `research` tab and nothing else; never read or change tasks. [proven, checked 2026-11-11] [scout](../../.claude/agents/scout.md)
- Read the page itself, prefer primary sources (the store page, the publisher), and record the date you saw it. [proven, checked 2026-11-11] [scout](../../.claude/agents/scout.md)
- Never write a number you did not see on a page. If you can't confirm it, say so and set confidence low. [proven, checked 2026-11-11] [scout](../../.claude/agents/scout.md)
- One row per finding: topic, type (keyword, competitor, trend, pricing or idea), one or two sentences, numbers, source URL, confidence (high, med, low), suggested action. [proven, checked 2026-11-11] [scout](../../.claude/agents/scout.md)
- With no topic, work the standing list: Amazon picture-book bestsellers for ages 2-6 in our themes, Etsy toddler printables and colouring pages, competitor pricing, seasonal hooks for the next 90 days. [proven, checked 2026-11-11] [scout](../../.claude/agents/scout.md)
- Before a new book starts, check whether the idea will sell: comparable titles, their ranks, review counts and prices. [proven, checked 2026-11-11] [scout](../../.claude/agents/scout.md)
- Treat ranks, prices and review counts as dated snapshots; say when you saw them, and re-check before using one in a listing or a plan. [unproven, checked 2026-11-11]
- Finish with the row IDs and the three findings that matter most. [proven, checked 2026-11-11] [scout](../../.claude/agents/scout.md)
