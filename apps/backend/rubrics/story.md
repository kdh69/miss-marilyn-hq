# QC rubric — story_draft

Read the series rules first: every Miss Marilyn book is ONE adventure teaching ONE lesson,
contains the "Achoo!" sneeze gag at least once, and ends with the "Meet the Real Miss Marilyn"
page (photo placeholder). 32 pages including title and copyright pages.

Blocking:
- Missing the lesson, the "Achoo!" gag, or the closing page (Miss Marilyn books only)
- Any spread over 60 words, or vocabulary a three-year-old wouldn't know without context
- No page plan, or a page plan missing text / art description / characters for any page
- Close imitation of an existing picture book
Minor: refrain strength, rhythm when read aloud.
