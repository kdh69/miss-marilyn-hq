# QC rubric — etsy_listing

Compare against the skus row, the printable files the listing sells, and the Scout research rows cited.

Blocking:
- Title over 140 characters, or stuffed with repeated keywords
- Not exactly 13 tags, any tag over 20 characters, or duplicate tags
- Any tag, title or description word that names another brand, book, character or author
- Description doesn't say plainly what the buyer gets: digital download, nothing shipped, file
  formats, US Letter and A4 sizes, page count, personal-use terms
- Description promises something the files don't contain, or claims we can't back
- Price missing or not matching the skus row
- Listing addresses children instead of parents and gift-givers
- File links missing from the packet
Minor: weak first line (the part shown in search), tag overlap with title, research rows not cited.
